01 / 电控向

软件篇 · 让机器人动起来

从点亮一颗 LED 到让电机和云台听话。按 51 单片机 → C 语言 → STM32 的顺序啃，配好开发板一路实操；51 与 STM32 各有一道考核题另加技术面试，考核题和面试都很重要。

  1. 51 单片机入门

    跟着江协科技 51 单片机教程从零学起，内容建议全部看完。需要自行购买一块 51 单片机开发板，边学边练。

  2. C 语言入门

    看浙江大学翁恺教程，学到 4.1.3 章节掌握基本知识即可，配合菜鸟教程边查边练。看不懂江协的代码，就回头补 C 语言。

  3. STM32 单片机

    江协科技 STM32 教程，难度比 51 单片机更大，同样建议全部看完，打通更强的片上外设。

  • 江协科技 · 51 单片机教程
  • 翁恺 · C 语言程序设计
  • 菜鸟教程 · C 语言教程
  • 江协科技 · STM32 教程
  • 下载路线原文档 (.docx)

路线终点 · 云台稳定控制不靠摄像头，光靠算法就让云台又快又稳地指向目标。

02 / 视觉向

软件篇 · 让机器人看得见

从处理一张图片到跑起自己的检测模型，一台电脑就能上路，全程不用碰单片机。

  1. Python 入门

    视觉方向的日常工具，语法学个大概就能开工，边写边查才是常态。

  2. OpenCV 图像处理

    读图、滤波、找轮廓、认颜色，先弄明白一张图在程序里是什么。

  3. 深度学习与 YOLO

    自己标数据、训模型，让机器人认目标，不用手写规则硬凑。

  4. 边缘设备部署

    把模型搬进 MaixCam、K230 这样巴掌大的设备，在真机上实时跑起来。

路线终点 · 实时目标识别报出目标的坐标，剩下的交给电控线。

03 / 硬件向

硬件篇 · 从一颗元件到一块主板

认识每一颗元件，读懂数据手册里的关键参数，最后让自己画的电路板真正通电运行。

  1. 元件认知

    熟悉电阻、电容、电感、二极管、三极管、MOS 管、比较器、运算放大器，跟着硬件工程师入门教程系统过一遍，建立元件手感。

  2. 电路基础与电源拓扑

    掌握基本电路定律之后，重点搞懂 LDO 与 DC-DC（BOOST、BUCK）电源方案的原理、取舍与选型，进阶可到立创 EDA 开源广场找开源项目跟着学。

  3. 嘉立创 EDA 设计

    跟着零基础入门 PCB 设计教程，了解并掌握原理图与 PCB 的绘制：自建元件封装、绘制原理图、完成 PCB 布线，把一块板子的设计流程从头走一遍。

  4. 焊接调试

    烙铁上的真功夫：焊得上、测得通、排得出故障，让自己设计的电路板第一次点亮。

  • 硬件工程师入门教程
  • 嘉立创 EDA · PCB 设计教程
  • 下载路线原文档 (.docx)

路线终点 · 智能小车主板以一块小车主板为载体贯穿全程，学完即可亲手把它装上车、跑起来。

04 / 机械向

机械篇 · 给机器人一副骨架

从草图约束开始，把想法变成图纸，再把图纸变成装得上、转得动的实物。

  1. SolidWorks 建模

    掌握草图约束与零件建模——建模思路比软件操作更重要，软件只是画笔。

  2. 装配体与工程图

    完成装配体设计与干涉检查，按国标规范出一张合格的工程图，让加工方看得懂、做得出。

  3. 3D 打印工艺与验证

    了解打印工艺与参数取舍，把自己设计的零件打出来、装上去、转起来，验证设计闭环。

路线终点 · 二轴云台支架设计并制造一副真正能用的云台支架——它与电控视觉组的瞄准闭环互为配套。

进阶交汇 · 视觉引导云台瞄准

两条线分开选、单独走都行，底子也是相通的：电控练出的 C 语言和串口功底，到视觉这边部署设备时直接就能用；反过来，电控平时也离不开用 Python 写的小工具。等各自走通，就能在这套项目里会合：视觉负责找到目标、报出位置，电控负责让云台稳定跟上。这套"看得见、瞄得准"的闭环，正是电子设计竞赛的主战场。

没学完，能进组吗？

适不适合成为我们的一员，看的不是起点高低，而是学习的热情与坚持——抱着热情持之以恒地学，克服途中的万难，胜任任何一个方向的组内工作都是水到渠成的事。
