01 / 电控视觉向

软件篇 · 让机器人动起来

从语言到系统，把知识一层层垒起来。每一步都有明确的练手目标，按顺序啃下来即可。

  1. 语言基础

    C 语言是嵌入式开发的地基，掌握基本语法和基本程序结构即可；C++ 的面向对象（封装、继承、派生）是实验室应用开发的环境语言，实习期会有相当长一段时间来适应。

  2. STM32 单片机开发

    电控视觉组的必备基础技能。技能点：单片机基础、Keil 与 CubeMX 使用、HAL 库工程、烧录工具、时钟树、GPIO、中断、定时器、串口通信。一定要在实践中学——能独立实现按键点灯，就可以进入下一步。

  3. FreeRTOS 实时系统

    跑在单片机上的微型操作系统，机器人的实时控制就建立在这基础之上。技能点：RTOS 基本原理、任务创建与调度、消息队列、信号量。试着设计一个多任务小项目，把 STM32 与 FreeRTOS 的知识串起来。

  4. 通信协议

    UART、SPI、IIC、CAN 四个常见协议的原理与使用。UART 是实验室最常用的板间通信，CAN 是驱动电机的基础，SPI 与 IIC 用来驱动陀螺仪等常见传感器。实习期前期任务，正是学会用这些协议把机器人上的常见电子器件驱动起来。

  5. 控制理论

    PID 是控制电机等系统最常用的基础算法，入门不要求完全理解推导，先从会用学起；滤波器（均值滤波、低通滤波、二阶低通）也是调试机器人时的常用算法工具。

  6. 拓展：机器人学与 SoC

    空间描述与变换、运动学、动力学——轮腿、平衡类机器人会用到，本质还是高中的几何与物理基础。同时，跑 Linux 的 SoC 开发也值得了解：装个虚拟机或 WSL，熟悉常用命令与脚本，再尝试驱动 GPIO、UART 等外设。

  7. 常用工具

    Keil / CubeMX / 串口助手 / J-Link / ST-Link / DAP-Link / VSCode / Git / MATLAB&Simulink / Webots。软件组的代码全部用 Git 托管、在 VSCode 上编写，Git 是必备的版本托管工具。

02 / 硬件向

硬件篇 · 让每一块电路可靠工作

从分立元件到整块电路板，一步步搭出你的第一件作品。看得懂原理图，也焊得牢电路。

  1. 元件

    实现功能的电路都由一个个分立元件搭建起来。先认识无源器件 RLC（电阻、电容、电感），再了解二极管（稳压、TVS、肖特基）、三极管、MOS 管与集成运放。之后看看什么是封装，翻翻数据手册里的耐压值、耐流值、漏电流与结电容。

  2. 电路基础

    学习基尔霍夫定律，理解 KVL 与 KCL 方程；理解频率与阻抗，看看电容电感在交流下的表现与时间常数 τ；从共射放大电路接触放大，思考静态工作点与波形失真的关系；学习运放的虚短虚断与一阶 RC 滤波（低通、高通）。有兴趣再搜搜伯德图。

  3. 电力电子技术

    LDO、开关电源、电荷泵——供电是一切可靠运行的前提。

  4. 单片机

    STM32 平台 + 通信协议（UART、SPI、IIC、CAN）。用一块最小系统板点亮第一盏灯、和电脑串口通信。硬件组也需要一定的软件开发能力，才能完成基本调试、对自己设计的 PCB debug。

  5. 工具使用

    EDA 软件：实验室统一使用 Altium Designer 21，也可以试试立创 EDA；仿真用 Multisim；单片机开发用 Keil / CubeMX / 串口助手。硬件工具：焊台、热风枪、镊子、锡膏、助焊剂、吸锡带；测试工具：万用表、示波器、学生电源、电子负载、手持数字电桥。
